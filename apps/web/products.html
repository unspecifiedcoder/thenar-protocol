Provenance and rights ledger

Four products for
physical-AI data

The provenance log is the centre. Capture attestation and rights management are the layers below and above it. Each is labelled with its honest state.

Provenance Report

Ingest an existing LeRobot v3 corpus, commit every episode to the log, run L3 checks (deduplication, jitter detection, plausibility), anchor, and deliver a counsel-readable report with proofs and an on-chain receipt. Needs no hardware, SDK, or contributors. First customer: a buyer or supplier closing a transaction and needing diligence.

FORMATLeRobot v3
CHECKSL3 heuristic
DELIVERYJSON + PDF + receipt
Building

Recorder SDK

A plugin for lerobot recorders that generates a session key, signs each episode's manifest at capture, and streams leaves to the log. Suppliers use this to be pre-verified so buyers skip the report stage. Optional device attestation (Android Key Attestation for Quest, TPM for NUC/Jetson). Where L1 signed claims and L2 attested claims originate.

PLATFORMSAndroid, Linux, iOS later
ATTESTATIONOptional, Phase D
DELIVERYnpm package
Planned

Licence Registry

On-chain corpus sealing, terms publication, and USDC settlement that binds payment to a specific corpus root and licence version in one transaction. Buyer approval starts delivery. Revocation tracking happens off chain; the API shows which corpora contain revoked episodes. No token, no token incentives.

CHAINAvalanche C-Chain primary
SETTLEMENTUSDC, 2.5% take
VERIFIERPublic, stateless
Building

Consent Service

For suppliers whose data comes from people: consent records, re-salted commitments per episode, signed revocation with on-chain onset proof, and erasure trails. GDPR-ready. Integrated with the Recorder SDK; independent for W1 suppliers.

SCOPEPer-episode consent
REVOCATIONSigned, onset proven
ERASUREVerifiable trail

Hardware research (not data products)

Thenar Band. A wrist unit for force/contact capture: watertight CAD, audited tolerances, printable today. Nobody has worn one; no data has been recorded with it. When force sensing wearables work, this design can be a reference L2 attestation device.
Hotaru. A desk robot: 22 printed parts, CAD in pure Python, open STLs, shipped. Proof of geometry and tolerancing discipline. Not a data product and not presented as one.
